# راهنمای سریع فارسی کتابخانهٔ پرامپت موشن گرافیک

این پوشه یک بستهٔ مستقل برای هدایت هوش مصنوعی‌های مختلف است. برای استفاده از آن لازم نیست حتماً Claude، ChatGPT یا Gemini خاصی داشته باشی. پرامپت‌ها را کپی کن و در دستیار یا ابزار تولیدی که واقعاً در اختیار داری قرار بده.

## داخل کتابخانه چه هست؟

- **۹۶ دستور سبک** با قواعد تصویری، حرکت، تایپوگرافی، رنگ، صدا، ساختار روایی و مواردی که باید از آن‌ها اجتناب شود.
- **۶ مستر پرامپت پایه** برای هدایت تولید.
- **۱۰ مستر پرامپت تخصصی** برای مستند، فیلم محصول، تایپوگرافی متحرک، نمودار، متن‌به‌ویدیو، تصویر‌به‌ویدیو، طراحی صدا، رندر کدنویسی‌شده، اصلاح پرامپت و کنترل کیفیت.
- **۱۵ الگوی صحنه** برای نوشتن دستور دقیق هر نما.
- **یک بستهٔ ۹ مرحله‌ای گردش کار** برای پژوهش، فیلمنامه، استوری‌بورد، موشن، صدا، بازبینی فریم، رندر و تعمیر.
- **صفحهٔ مرورگر** برای جست‌وجو، فیلترکردن، ترکیب، کپی و دانلود پرامپت.

## روش اول: استفاده از صفحهٔ مرورگر

از پوشهٔ اصلی مخزن اجرا کن:

```bash
python -m http.server 8765
```

سپس در مرورگر باز کن:

```text
http://localhost:8765/prompt-library/
```

یک سبک را انتخاب کن، در صورت نیاز مستر پرامپت تخصصی و الگوی صحنه را اضافه کن، سپس **Copy full prompt** را بزن یا فایل Markdown بگیر. صفحه فایل‌های همین مخزن را می‌خواند و خودش هیچ API پولی را فراخوانی نمی‌کند. بازکردن مستقیم فایل HTML با `file://` ممکن است به‌دلیل محدودیت مرورگر اجازهٔ خواندن فایل‌های داده را ندهد.

## روش دوم: استفاده از خط فرمان

```bash
npm run prompts:list
npm run prompts:search -- typography
npm run prompts:show -- motion-design-showreel
npm run prompts:show -- kinetic-data-symphony --format json
npm run prompts:export -- --category product-ui
npm run prompts:master
```

برای جست‌وجو از واژه‌های انگلیسی سبک استفاده کن، چون شناسه‌ها و دسته‌بندی‌های کتابخانه انگلیسی هستند.

## چطور از یک مستر پرامپت درست استفاده کنیم؟

۱. یک ایده و هدف مشخص بنویس: ویدیو باید چه چیزی را توضیح دهد یا در مخاطب چه حسی بسازد؟  
۲. یک سبک اصلی انتخاب کن. در نهایت حداکثر دو روش تصویری مکمل اضافه کن تا ویدیو به مجموعه‌ای بی‌ربط از افکت‌ها تبدیل نشود.  
۳. مستر پرامپت عمومی را با دستور سبک ترکیب کن. برای یک کار تخصصی، فقط بخش مرتبط از فایل `ADVANCED_MASTER_PROMPTS.md` را هم اضافه کن.  
۴. برای هر صحنه از `SCENE_PROMPT_TEMPLATES.md` استفاده کن و زمان، ترکیب‌بندی، یک حرکت اصلی سوژه، یک حرکت دوربین، مسیر حرکت، نقطهٔ پایان، رنگ و صدا را روشن کن.  
۵. ابتدا استوری‌بورد زمان‌بندی‌شده و چند فریم آزمایشی بساز. بعد یک یا دو ایراد واقعی را در هر دور اصلاح کن. اضافه‌کردن بی‌پایان صفت‌هایی مثل «سینمایی» یا «خفن» جای دستور دقیق حرکت را نمی‌گیرد.  
۶. متن دقیق، لوگو، برچسب نمودار و زیرنویس را تا حد امکان در کامپوزیتور اضافه کن، چون مدل‌های ویدیویی ممکن است حروف و کلمات را خراب کنند.  
۷. قبل از تحویل، خود ویدیو، صدای واقعی، وضوح متن، تداوم صحنه‌ها، نسبت تصویر و زیرنویس را بررسی کن.

## چند شناسهٔ آماده برای شروع

- `motion-design-showreel`: شو‌ریل مفهومی که شکل‌ها و نوشته‌ها را به صحنهٔ بعدی تبدیل می‌کند.
- `kinetic-type`: تایپوگرافی متحرک و ریتم کلمات.
- `product-ui-state-morph`: تبدیل پیوستهٔ یک المان رابط کاربری میان حالت‌های مختلف.
- `kinetic-data-symphony`: روایت داده با نمودار و حرکت هماهنگ.
- `seamless-motion-loop`: طراحی چرخه‌ای که ابتدا و انتهای آن با هم جور باشند.
- `multilingual-motion-explainer`: ویدیوی چندزبانه با قواعد درست چینش و خوانایی متن.
- `cinematic-map-journey`: حرکت روی نقشه و مسیر جغرافیایی.

## اتصال کتابخانه به موتور تولید پروژه

نمونهٔ ساخت برنامه‌ریزی تولید با یک دستور مشخص:

```bash
npm run produce -- --topic "A concept-led motion design showreel" --language en --duration 30 --prompt-recipe motion-design-showreel --plan-only --voice off
```

گزینهٔ `--prompt-recipe` دستور انتخابی را در خروجی تولید ثبت می‌کند و در حالت سبک خودکار، دستهٔ آن را به یک سبک پشتیبانی‌شدهٔ Remotion نگاشت می‌کند. اگر یک تولیدکنندهٔ استوری‌بورد AI با کلید API و اجازهٔ صریح پیکربندی شده باشد، جزئیات دستور نیز به آن داده می‌شود.

**محدودیت مهم:** موتور محلی همهٔ ۹۶ سبک را با تمام جلوه‌های اختصاصی آن‌ها پیاده‌سازی نمی‌کند. در حالت جایگزین محلی، فقط نگاشت به سبک پشتیبانی‌شده انجام می‌شود و گزارش QC این محدودیت را اعلام می‌کند. داشتن یک پرامپت به‌معنای نصب‌شدن ابزار خارجی، امکان ساخت هر جلوه یا فعال‌بودن API پولی نیست. برای فراخوانی سرویس‌های پولی باید متغیرها و اجازهٔ مربوط به آن‌ها را صریحاً تنظیم کنی.

## تحقیق روی ویدیوهای مرجع

صفحهٔ عمومی یک ویدیو می‌تواند عنوان، پرامپت یا توضیح ساخت را نشان دهد، اما به‌تنهایی اثبات نمی‌کند که تمام ویدیو تماشا یا تحلیل فریم‌به‌فریم شده است. در کاتالوگ پروژه سطح شواهد L0 تا L3 حفظ می‌شود؛ صفحهٔ بررسی‌شده L1 است، تماشای کامل L2 و تحلیل زمان‌بندی‌شده همراه با شواهد فریم L3 است.

از نمونه‌ها اصول کلی مثل پیوستگی حرکت، ریتم، محدودکردن رنگ‌ها، توابع زمانی قطعی و بررسی فریم‌های آزمایشی را استخراج کن و یک اجرای تازه بساز؛ کل پرامپت یا نماهای اختصاصی سازنده را بدون اجازه کپی نکن. شرایط استفادهٔ هر منبع را رعایت کن: Pinterest را به‌صورت خودکار خزش نکن و فریم‌های FilmGrab را به‌صورت انبوه دانلود یا بازنشر نکن.

## راهنمای اصلی انگلیسی

برای خروجی قابل‌کپی و بیشترین سازگاری با ابزارها، فایل `MASTER_PROMPT.md` و پرامپت‌های انگلیسی داخل کاتالوگ را همراه با موضوع و محدودیت‌های خودت به هوش مصنوعی بده. این راهنمای فارسی برای انتخاب و استفاده است؛ پرامپت دقیق معمولاً با زبان و قالبی که موتور هدف بهتر پشتیبانی می‌کند بهتر عمل می‌کند.

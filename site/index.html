رفتن به صفحه تولید ↗
  1. تنظیمات را آماده کن.
  2. اگر GitHub CLI در Termux نصب و وارد حساب شده است، دستور GitHub Actions را کپی و اجرا کن؛ همه انتخاب‌ها به‌طور خودکار ارسال می‌شوند.
  3. برای اجرای دستی، صفحهٔ workflow را باز کن و همان گزینه‌ها را وارد کن.
  4. فایل MP4 و فایل SHA256SUMS.txt را از بخش Artifacts دریافت کن.
⌑
امنیت در اولویت است

کلید را در فرم این سایت وارد نکن. در مخزن GitHub به Settings → Secrets and variables → Actions برو و کلید را با نام ANTHROPIC_API_KEY اضافه کن. برای جست‌وجوی وب، FIRECRAWL_API_KEY اختیاری است. Secrets در کد فرانت‌اند قرار نمی‌گیرند و استفاده از AI پولی نیازمند انتخاب صریح است.

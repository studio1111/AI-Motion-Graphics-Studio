# Claude Code Project Skills

Claude Code discovers skills at `.claude/skills/<skill-name>/SKILL.md`. These five skills are written for this repository and point to shared reference documents.

- `autonomous-motion-studio`: orchestrate research, script, storyboard, build and quality review with sensible defaults.
- `motion-style-engine`: select a style preset and lock fonts, colors, composition, movement and continuity.
- `kinetic-type-audio`: coordinate typography, narration, music, effects, silence and captions.
- `reference-research`: gather references with evidence levels and deduplication.
- `automated-render-qa`: test, render, inspect and report output honestly.

Read these central files for each project:
- `CLAUDE.md`: persistent project rules and autonomy contract.
- `docs/MOTION_STYLE_BIBLE.md`: twelve distinct visual families.
- `docs/STYLE_PRESET_CATALOG.md`: twelve parameterized style presets, font candidates, palettes, motion and sound.
- `docs/MOTION_DESIGN_SYSTEM.md`: typography, composition, transitions, rhythm, sound and accessibility.
- `docs/AUTONOMOUS_PRODUCTION_PIPELINE.md`: stage machine and quality gates.
- `prompts/CLAUDE_AUTONOMOUS_STUDIO_PROMPT.md`: orchestration prompt.
- `prompts/STYLE_RECIPE_LIBRARY.md`: scene-specific recipes.
- `docs/REFERENCE_PATTERN_MATRIX.md`: article-level benchmark patterns and limitations.
- `docs/RESEARCH_AND_BENCHMARK_PLAN.md`: 1,000-reference study target and evidence levels.

The broader 26-skill catalogue remains under `.agents/skills/`. A skill file is an instruction set, not proof that the described external software has been installed.

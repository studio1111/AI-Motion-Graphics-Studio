# Claude Code Project Skills

Claude Code discovers project skills at `.claude/skills/<skill-name>/SKILL.md`. These skills point to the repository's detailed production references.

- `autonomous-motion-studio`: coordinate end-to-end production with sensible defaults.
- `motion-style-engine`: select coherent style grammar and scene-level motion.
- `kinetic-type-audio`: coordinate typography, narration, music, effects, silence and captions.
- `reference-research`: research public references with evidence levels and deduplication.
- `automated-render-qa`: run and report render/quality gates.

The broader 26-skill catalogue lives under `.agents/skills/`. Do not assume Claude Code automatically discovers that separate directory.

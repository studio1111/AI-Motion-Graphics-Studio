# Animated Infographics

1. Validate the data source, units, dates, labels, and intended takeaway.
2. Choose a visual encoding that matches the data; do not distort scales to make a point.
3. Establish hierarchy and explain the chart before animating it.
4. Animate changes from a clear baseline; preserve comparability between states.
5. Keep labels attached to their data and avoid overlapping annotations.
6. Provide source notes and accessible color/label alternatives.
7. Use frame-deterministic animation for video rendering and include a static fallback.

Never invent missing values or imply causation from correlation. Validate the final rendered frames for label clipping, legibility, and factual accuracy.

# SVG and Lottie Animation

- Use SVG for crisp paths, masks, gradients, and scalable graphic elements.
- Plan path direction, stroke width, viewBox, and anchor geometry before animating.
- Keep vector paths and layer names organized for editing.
- For Lottie, verify which effects, masks, expressions, and blend modes are supported by the target player.
- Avoid unsupported After Effects effects when the output must be portable Lottie JSON.
- Preview on the actual target player and platform, not only in the authoring tool.
- Optimize path complexity and asset size without changing appearance.
- Respect the license of any plugin, font, template, or source asset.

Official references: https://lottiefiles.com/ and https://developer.mozilla.org/en-US/docs/Web/SVG

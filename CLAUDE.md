# AI Motion Graphics Studio
## Start here
Read relevant skills under `.claude/skills/`, then `docs/MOTION_STYLE_BIBLE.md`, `docs/MOTION_DESIGN_SYSTEM.md`, `docs/AUTONOMOUS_PRODUCTION_PIPELINE.md` and `prompts/CLAUDE_AUTONOMOUS_STUDIO_PROMPT.md`.

## Mission and autonomy
Operate as a production team: researcher, writer, art director, storyboard artist, animator, editor, sound designer, and render engineer. Deliver the best video supported by the real environment. Do not stop at a prompt/storyboard if build and render are possible. Use existing preferences. Infer non-critical details and record them rather than asking aesthetic questions. Default to the request language, 16:9, 1920×1080, 30 fps and about 90 seconds unless context says otherwise. Select one lead style plus at most two accents.

Use deterministic rendering for exact typography, data, diagrams, maps, labels, timing and captions. Use generated imagery as plates and composite precise text later. Check tool availability, schemas, costs, licenses and quotas before installation/generation. Never silently substitute paid cloud services for a requested free/local method. Keep the removed “Why is the sky blue?” example removed; MotionDemo is only a technical smoke test.

## Truth and evidence
Never claim a tool is installed unless checked in runtime. Do not call metadata or transcript review a full-video analysis. Never invent data, sources, outputs or QC. Mark each check PASS, FAIL, BLOCKED or NOT RUN.

## Production loop
Brief → research → narrative → style lock → storyboard/scene manifest → asset/rights plan → voice/audio timing → build → preview → frame/audio/technical review → bounded repair → final render → final QC → package. Persist intermediate outputs to avoid repeating expensive steps.

## Quality bar
Every scene should reveal, compare, transform, reframe, explain or carry emotion. Avoid static title slides, generic gradients, perpetual zoom, tiny labels, random effects and unmotivated whooshes. Give important text time to settle and read. Report defects honestly.

## Implementation boundary
The repository has a Remotion smoke-test pipeline plus skills/prompts. Do not claim unattended topic-to-final-video generation until executable code, configured services, tests and a real final artifact prove it.
